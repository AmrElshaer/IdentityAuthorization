## 🧠 Sonar Analysis Enforcement

After suggesting or writing any code, always:

1. Run the Sonar/MCP analysis tool or script for this project using analysis code snippet.
2. Ensure the generated code passes the Sonar quality gate for:
   - Security
   - Reliability
   - Maintainability
3. Run SonarQube and check for bugs and vulnerabilities.
Do not finalize or commit code until the Sonar analysis confirms it passes all checks.
